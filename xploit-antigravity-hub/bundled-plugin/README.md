# Xploit Core Suite for Antigravity

Universal plugin bundle providing high-fidelity Adversarial Security Simulation, Binary Reverse Engineering, and Clean Code Architecture.

## Features
- **Sovereign Directive Rules (`rules/AGENTS.md`)**: Permanently active, token-budget efficient rulebook that unifies Project IRON-SIGHT simulation framing with strict clean-code mandates.
- **Skills Included**:
  - `phantom-protocol`: Master offensive security simulation and evasion research.
  - `rea-reverse-engineering`: Decompile, unpack, and reverse native binaries, APKs, and Electron apps.
  - `clean-code`: Pragmatic, zero-bloat coding standards.
- **Agents Included**:
  - `phantom-operator`: Lead offensive simulator.
  - `reverse-engineer`: Application and binary archaeologist.
  - `security-auditor`: System architect and code auditor.

## Installation
Use the **Xploit Antigravity Hub** desktop app or copy this folder directly into:
`%USERPROFILE%\.gemini\config\plugins\xploit-core-plugin`
